# 課題1
## 解答
### Vercel

フロントエンド特化のクラウドサービスで、グローバルCDNによる高速配信や自動CI/CD、サーバーレス関数を提供。データベース等の永続化は外部サービスとの統合で対応する。

- 無料枠の内容

無料プランでは、グローバルCDN、自動HTTPS、WAFを含み、月100GBまでの帯域、サーバーレス関数10万リクエスト、Edge Functions50万回が無料。ただし超過分は従量課金となる。

- APIの使いやすさ

REST API、公式のTypeScript SDK、CLIが提供されており、プロジェクト管理やデプロイ操作をプログラムから簡単に実行できる。ドキュメントは充実しており、使いやすい。

- ドキュメントや開発者向けリソース

公式ドキュメントやガイド、Next.js特化の解説が充実。公式フォーラム、GitHubテンプレート、Marketplace連携などコミュニティの学習リソースも豊富で情報収集が容易。

- その他のメリット・デメリット

Git連携でプレビューURL付きの自動デプロイが可能で、高速かつセキュア。反面、高度なバックエンド処理や長時間処理は苦手で、永続データは外部サービス頼み。規模拡大時は費用が高額化する場合もある。

### Netlify

静的・Jamstackサイト向けのホスティングで、Git連携の自動デプロイ、サーバーレス・Edge Functionsを提供。DBは外部連携型で、FaunaDBなどとの統合も簡単。

- 無料枠の内容

帯域100GB/月、ビルド時間300分/月、サーバーレス関数12.5万回、Edge関数100万回/月など充実。500サイトまで無料で作成可能だが、超過分は従量課金される。

- APIの使いやすさ

REST APIとOpenAPI仕様を公開し、公式CLIやSDKも充実。デプロイや設定変更をスクリプトで簡単に行え、ドキュメントや利用例も豊富で使いやすい。

- ドキュメントや開発者向けリソース

公式ドキュメントは充実しており、各種フレームワーク向けのスターターキット、公式フォーラム、ブログ、プラグイン、サンプルコードが豊富で情報収集が容易。

- その他のメリット・デメリット

Jamstack構築に必要な機能を一元提供しフォームや認証も手軽だが、SSR対応はやや遅れた。サーバーレス関数は実行時間が短く、大規模チーム利用時は割高になる。

### Cloudflare

CDNをベースにした静的サイトのホスティング（Pages）とエッジで動くサーバーレス環境（Workers）を提供。KVやR2ストレージ、SQLite互換のD1などのデータストアと統合可能。

- 無料枠の内容

無料プランは寛容で、Pagesは月500回のビルド、Workersは日10万リクエスト、KVストア利用枠も豊富。SSLやDDoS保護等のセキュリティ機能も無料で充実。

- APIの使いやすさ

RESTfulなAPIを提供し、公式CLI（wrangler）やTerraformにも対応。ドキュメントやサンプルが豊富で、KVやR2など各機能をプログラムやコード管理で自在に操作可能。

- ドキュメントや開発者向けリソース

公式ドキュメントは詳細で体系的。チュートリアル、ブログ、サンプルコードが充実し、コミュニティフォーラムも活発なため、情報収集や問題解決が容易。

- その他のメリット・デメリット

世界的なエッジネットワークにより高速かつセキュア。料金体系も安価だが、Node.js等と互換性の制約あり。SSRは非公式対応であり、D1等のDB機能はまだ発展途上。

### Supabase

- 提供している機能

マネージドPostgreSQLを中心に、リアルタイムDB、認証、ストレージ、Edge Functionsを提供するBaaS。フロントエンドのホスティングは別サービス（例：Vercel）との併用が前提。

- 無料枠の内容

データベース容量500MB、月間転送量5GB、認証ユーザ5万人、ストレージ1GB、APIリクエスト無制限の無料プランを提供。超過時は自動停止で、安心して利用可能。

- APIの使いやすさ

DBスキーマから自動生成されるRESTやGraphQL APIを提供し、公式SDK（JS, Flutter, Swift等）が充実。Firebaseのような直感的な操作性で学習コストは低い。

- ドキュメントや開発者向けリソース

公式ドキュメントは詳しく体系的で、各フレームワーク別の導入ガイドやサンプルが豊富。活発なDiscordやGitHub Discussions、オープンソースで透明性も高い。

- その他のメリット・デメリット

迅速にバックエンドを構築可能でSQLの柔軟性が魅力だが、フロントエンドホスティングは非対応。無料枠は本番利用には厳しく、大規模運用では性能や拡張性に限界あり。
